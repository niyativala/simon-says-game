# 🎮 Simon Says Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**.  
This project tests the player’s memory by generating random color sequences that must be repeated correctly.

---

## 🚀 Features

- 🎯 Random color sequence generation  
- 🧠 Memory-based gameplay  
- 📈 Level progression system  
- ✨ Flash animations and effects  
- 🎨 Modern responsive UI  
- 🔄 Restart game functionality  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  

---

## 📂 Project Structure

index.html → Game structure and UI  
style.css → Styling, animations, and responsive design  
app.js → Game logic and sequence handling  

---

## ⚙️ How It Works

1. Press any key to start the game  
2. The game flashes a random color  
3. Player must repeat the same sequence  
4. Sequence increases every level  
5. Wrong sequence ends the game  

---

## ▶️ How to Run Project

1. Download or clone this repository
2. Open `index.html` in your browser
3. Start playing 🎮

---

### 📊 Project Logic (Simple)

* Game generates random color patterns  
* User clicks buttons in correct order  
* JavaScript compares user sequence with game sequence  
* Correct sequence increases level  
* Wrong sequence triggers Game Over
